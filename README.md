# Cours de largage

Simulation animée d'un largage, pour illustrer le cours du brevet C (et du BPA) : l'avion, les sorties, la chute, l'ouverture, et les écarts entre paras (en rouge quand deux paras qui se suivent sont à moins de 250 m l'un de l'autre au même instant ; le bouton Auto calcule le temps entre sorties pour 300 m au sol à la sortie, avec le vent).

Ce n'est pas un outil de préparation d'un vrai largage.

Appli en ligne : https://henrinls.github.io/cours-largage/
